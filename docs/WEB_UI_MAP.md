### 2.2 侧栏高亮归属

注册表每个页面的 `nav` 字段（`.nav` 的 `data-page`）：`applyRoute` 点亮 `data-page` 等于它的那一项；`skipped`、`groups`、`group` 归未识别；`pending` 归已排除；`similar`、`sgroup` 归重复；`settings` 点亮侧栏底部的设置链接。资料库、首页、图库各自一项；`artist-audit` 的 `nav` 为空，侧栏无高亮。

### 2.3 点击语义

注册表的 `click` 字段决定一页的点击行为，`core/route.js` 里的两个判断函数从它派生：

- `browsing()`（`click: 'browse'`）：非角色筛选下的 `library`、`duplicates`。点击打开详情；选择需要显式进入（⌘／Ctrl 点击、左上角圆圈、工具栏「选择」、拖动）。
- `cleanup()`（`click: 'cleanup'`）：角色筛选，或 `unmatched`、`skipped`、`excluded`、`pending`、`group`、`sgroup`、`audit`。点击切换选中；工具栏按钮是「全选」；↵ 切换光标处那张的选中。
- 首页和面板页是 `'own'`，不走网格。首页有自己的点击处理：`.home-j` 打开详情，不涉及选择。

另有 `panel` 字段：主区不是 `#grid` 的页面都为真（`home`、`characters`、`settings`、`groups`、`similar`、`identity`、`artist-audit`）。R、`reload()`、同步到达新图和 R18 切换后的重绘都用它判断：面板页自己重画，不会被换成网格。

`keys` 字段（`keyScope()`）是单图快捷键的范围：网格页为 `'grid'`（全部生效）；首页为 `'shown'`，没有网格光标，只在详情栏或大图打开时对那张图生效（见 §5）；其余面板页不响应。

### 2.4 标题与底栏提示

标题由各页在 `ui/shell.js` 末尾登记的 `heading` 函数返回（`[标题, 副标题, 右侧链接]`）；角色页有专属标题（`drawHeading`：名称、张数、未检查、检查日期、「关联 Danbooru」，右侧按钮：按相似细分、标为已检查、⋯ 菜单）；`group` 页另有「整组标为原创角色」，`sgroup` 页另有「判断关系」，资料库角色页另有「N 个自建角色能对上 Danbooru」。

底栏提示（`hint`）和空状态文案（`empty`）写在注册表里，由 `grid.js` 的 `updateCount` 和 `reload` 读（网格页），各面板页的渲染函数自己写。`similar`、`sgroup`、`group` 没有底栏提示；没有登记 `empty`／`hint` 的页面这两处为空。

## 3. 浮层

页面上所有"盖在别的东西上面"的层，开、关的先后顺序记在一个栈里，由 `ui/overlay.js`（浮层管理器，#343）统一处理 Esc、点外关闭和焦点归还。各浮层只声明自己是什么类型、怎么关；除管理器之外，前端不再有谁为浮层监听 `document` 的 `keydown` 或 `click`；`tools/check_frontend.py` 的规则 3 只放行 `ui/overlay.js` 这一个文件（用户 2026-11-12 在 #343 批准）。

### 3.1 浮层管理器怎么工作

三种类型（`kind`）：

| 类型 | 是什么 | 点外／点背景 |
|---|---|---|
| `modal` | 模态对话框：`<dialog>` 经 `openModal` 打开。浏览器把它放在顶层，高于所有 `z-index` | 点背景是否关闭由调用点声明（`backdropClose`，默认不关）；它之下的层不响应点外关闭 |
| `popover` | 非模态浮层：菜单、面板、搜索候选 | 点它和它的触发按钮之外的任何地方关闭（点按钮由按钮自己的处理函数开关） |
| `overlay` | 盖满页面的层：导览、大图 | 无 |

规则：

1. **栈按打开的先后排**，后开的在上面。元素被换掉、被藏起来（自己或祖先 `hidden`）、对话框已经关了的层，在下一次 Esc 或点击时自动清出栈，不白占一次按键。
2. **Esc 只关栈顶一个。** 事件在 `document` 捕获阶段处理，处理了就 `preventDefault` 并停止传播，所以同一次按键不会再触发页面别处。对话框由管理器自己 `close()`，返回值与原生取消相同。**栈是空的就放行**，接着走页面自己的 Esc 兜底链（`grid.js`）：输入框失焦 → 详情栏 → 取消选择并退出选择模式。
3. **输入框里按 Esc 只关候选菜单。** 搜索候选菜单（编辑资料、新建作品的 Danbooru 框，资料库"添加关注"）本身是 `popover` 层，叠在所在的对话框或页面上面：它在栈顶，第一下 Esc 只关它，输入框和对话框都留着，第二下才轮到下面一层。
4. **大图让位给输入框。** 大图层声明了 `yieldToInput`：焦点在大图之外的输入框里时，Esc 不关大图，只让输入框失焦（兜底链做）。其余层不让位，例如视图选项打开时，焦点在搜索框里按 Esc 先关视图选项。
5. **点外关闭从栈顶往下数，到第一个 `modal` 为止。** 栈顶的 `popover` 若点在它自己和触发按钮之外就关闭，继续往下看；遇到 `modal` 时只看这次点击是不是它声明了可以关的背景点击，然后停止，所以对话框下面的任务面板不会被对话框里的点击关掉。一次点击可以同时关掉几个它在外面的 `popover`，点中的那个不关。点击本身照常交给被点的元素处理（不吞掉）。
6. **点背景关闭（`openDialog` 的 `backdropClose`，默认 `false`，每个调用点显式写明）：** 只读或确认类（帮助、确认／通知、关系、"按相似细分"、命令面板、只当标签）为 `true`；带输入或选项的表单（编辑资料、新建／编辑作品及关注、关联自建角色、添加新角色、选作品）为 `false`，免得误点丢掉填的东西。
7. **焦点：** 层打开时记下当时的焦点元素。Esc 或选了一项关闭后，焦点还给它（它没了就还给触发按钮），只在焦点仍在层里或在 `body` 上时才还，不从别处抢。点外关闭、页面重画导致的关闭不动焦点。对话框的焦点由浏览器归还。
8. **层级（`z-index`）不由管理器写**，仍是 `app.css` 的 `--z-*` 令牌：非模态浮层 `--z-popover`／`--z-menu`／`--z-overlay`、大图 `--z-overlay`、导览 `--z-guide-tour`；原生 modal 在顶层。栈序决定 Esc 和点外，CSS 决定谁画在上面；两者在正常流程里一致（后开的在上面）。

新增一个浮层：`createLayer({kind, id, el, anchor, onDismiss, …})`（元素会被重画换掉的传函数），打开时 `layer.open()`，用任何途径关掉时 `layer.close(reason)`；`<dialog>` 用 `openModal(dialog, {backdropClose})`，运行时对话框用 `openDialog`（`ui/dialog.js`）。单元测试在 `tests/overlay.test.cjs`。

### 3.3 一次 Esc 的去向

1. 栈里有层：关栈顶那一个，到此为止（大图在焦点位于其外的输入框时除外，见规则 4）。栈里的次序一般就是打开的先后，例如导览 → 任务面板：先关任务面板，再关导览；任务面板 → 它上面开的确认框：先关确认框；对话框 → 它里面的搜索候选：先关候选。
2. 栈空，走 `grid.js` 的兜底链（键盘处理里 `<dialog>` 打开时整个忽略，所以对话框开着时到不了这里）：焦点在输入框 → 只让它失焦；否则详情栏打开 → 关详情栏；否则取消选择并退出选择模式。

### 4.1 选择栏按钮

| 页面 | 按钮 |
|---|---|
| 角色页（「可能也是 TA」） | 是 X｜不是 TA ⌫ |
| 角色页 | 不是 X ⌫｜换成… C｜也是… A｜子标签 T（有皮肤时） |

| 待确认 | 排除 X｜保留 |

## 6. 状态组合

状态字段全部声明在 `core/state.js`，按归属分组，每组只有一个写入者（组标题写明），别的模块要改就调用写入者的函数（#344）；`tools/check_frontend.py` 规则 7 检查别的文件有没有给这些字段赋值（#353）。图片交互的四个模式由下面这些字段组成，组成方式、叠加规则、当前图来源和快捷键动作表写在 `core/modes.js`（单元测试 `tests/modes.test.cjs`）。

| 字段 | 含义 | 写入者 |
|---|---|---|
| `selecting` | 选择模式（浏览页点图不再打开详情） | `grid.js`（别处用 `quitSelecting`、`resetForRoute`） |
| `sel`、`anchor`、`armed` | 选中集（`all` ＋ `ids` ＋ `exclude`）、连选起点、等待第二次点击的破坏性按钮 | `grid.js` |
| `cursor` | 键盘光标（序号） | `grid.js`（详情栏、大图翻页用 `setCursor`） |
| `focused`、`detail`、`question` | 详情栏里那张图（`null` ＝关）、详情接口最近一次返回、问题条 | `detail.js` |
| `viewer`、`viewerItem` | 大图的序号（`-1` ＝关）和那张图 | `detail.js` |
| `kept.hold`（不在 state） | 列表变化时保持在视野里的那张图 | `grid.js`、`detail.js` |

模式与叠加规则：

- **浏览**：没有选中、不在选择模式、没有详情栏、没有大图。
- **选择**：选中至少一张，或浏览页进了选择模式还没选（选择栏只在选中数 > 0 时出现）。
- **详情**：详情栏打开。可与选择同时在，此时单图快捷键先作用于选中的图（选择栏）。
- **大图**：盖住网格、选择栏和详情栏。快捷键只作用于大图那张：C／A／⌫／X／G／S／T／1–9 按「没有选中」处理，⌘A 不改选择，Y／N 不回答选中的抽查；选中保留，关掉大图后照旧，但在大图里改了那张图（快捷键或大图上的按钮）之后，和其他写入一样清空选择。
- **当前图**：大图 ＞ 详情栏 ＞ 光标（`currentSource`）；Space 打开的是光标 ＞ 详情栏 ＞ 第一张（`viewerTarget`）。

### 6.1 组合

| 组合 | 是否出现 | 说明 |
|---|---|---|
| 全无 | 默认 | 浏览 |
| `selecting=true`、`sel` 空 | 可达 | 浏览页点了「选择」；选择栏不显示，卡片显示圆圈 |
| `selecting=false`、`sel` 非空 | 可达 | 整理页点一张就选中 |
| `selecting=true`、`sel` 非空 | 可达 | 浏览页选择模式下 |
| `focused` ＋ `sel` 非空 | 可达 | 详情栏和选择栏同时在；有选中时走选择动作 |
| `viewer>=0` ＋ `focused` | 可达 | 从详情栏放大；Esc 先关大图，再关详情栏 |
| `viewer>=0`、`focused` 空 | 可达 | 双击卡片直接开大图 |
| `viewer>=0` ＋ `sel` 非空 | 可达 | 选择栏在大图下方，不响应快捷键 |
| `armed` 非空 | 只在 `sel` > 500 张时 | 换页、清选择、4 秒后复位 |
| `question` 非空 | 有问题条时 | 离开详情栏（无大图时）清空；大图关闭不清，但 Y／N 会核对问题对应的图 |
| `focused` 有值、`detail` 空 | 短暂 | 详情读取中 |
| `detail` 有值、`focused` 空、`viewer<0` | 可达 | 只开过大图后：1–9 要求详情栏或大图在用，不会误触 |
| 换页（`applyRoute`） | | 关大图（不动焦点）；复位 `selecting`、`sel`、`cursor`；详情栏只在换了页面或角色时关 |
| 切换 R18 | | 清选择；不关详情栏、不关大图 |
