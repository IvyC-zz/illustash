## 1. 常驻骨架

`index.html` 里的固定区域，所有页面共用。每个页面只是决定这些区域里放什么、哪些隐藏。

| 区域 | 元素 | 内容 | 谁写它 |
|---|---|---|---|
| 侧栏 | `#sidebar` | 标志与图库名；首页、图库、资料库；「整理」下：新加入（永远隐藏）、未识别、随机抽查（有题才显示）、重复、已排除、身份整理（有题才显示）；底部：任务按钮、设置 | `shell.js`（高亮、计数、条件显示）；`tasks.js`（任务按钮） |
| 顶栏 | `.topbar` | ☰ 切换侧栏；`#heading` 页面标题；跳到角色（⌘K）、R18、视图选项、撤销、快捷键 | `shell.js renderHeading`；`grid.js`（R18、视图选项）；`app.js`（撤销、帮助） |
| 工具栏 | `#toolbar` | 每页自己的一行：搜索、子页签、筛选胶囊、排序、选择、显示方式 | `shell.js renderChrome` |
| 横幅 | `#errorBanner`、`#damageBanner`、`#guideNotice` | 读写出错或页面停止；数据库损坏；识别组件缺失、同步中断、模型未就位 | `dom.js error()`；`integrity.js`；`guide.js` |
| 主区 | `#viewport` 内 6 个互斥面板 | `#grid`（图片网格，配 `#marquee`、`#empty`）、`#charIndex`、`#settingsPage`、`#groupsPage`、`#homePage` | 各页面的渲染函数，见 §2 |
| 底栏 | `.footer` | `#resultCount` 张数、`#hint` 本页操作提示；**默认隐藏**（视图选项「底部状态栏」，默认关） | `grid.js updateCount`、各渲染函数 |
| 详情栏 | `#inspector` | 一张图的详情，见 §4 | `detail.js` |
| 浮层 | 见 §3 | | |

主区的 6 个面板互斥，但没有统一的切换函数：每个渲染函数（`renderHome`、`renderIndex`、`renderSettings`、`renderGroups`、`renderSimilar`、`renderIdentity`、`renderArtistAudit`、`reload`）开头各自手写一遍「隐藏另外几个、显示自己」，`#homePage` 的显隐另在 `applyRoute` 里设。

侧栏切换：≤760px 宽时 ☰ 切换 `.mobile-open`（抽屉），否则切换侧栏的 `hidden`；每次换页都会收起抽屉。

### 2.2 侧栏高亮归属

`shell.js applyRoute` 里的一条手写映射：`data-page` 等于页面名，另加 `skipped`、`groups`、`group` → 未识别；`pending` → 已排除；`similar`、`sgroup` → 重复。资料库、设置、首页、图库各自一项；`artist-audit` 没有入口，侧栏无高亮。

### 2.3 点击语义

`core/route.js` 里两个判断函数决定一页的点击行为，页面清单是手写的：

- `browsing()`：非角色筛选下的 `library`、`duplicates`、`recent`。点击打开详情；选择需要显式进入（⌘／Ctrl 点击、左上角圆圈、工具栏「选择」、拖动）。
- `cleanup()`：角色筛选，或 `unmatched`、`skipped`、`excluded`、`pending`、`group`、`audit`。点击切换选中；工具栏按钮是「全选」。
- 其余（`sgroup`；首页和面板页不走网格）两个函数都为假。
- 首页有自己的点击处理：`.home-j` 打开详情，不涉及选择。

另有 `panelPage()`：`home`、`characters`、`settings`、`groups`、`similar`、`identity` 为真（不用 `#grid`），`artist-audit` 不在其中。网格相关的快捷键、`reload()`、R18 切换后的重绘都用它判断。

### 2.4 标题与底栏提示

标题在 `shell.js renderHeading`：角色页有专属标题（名称、张数、未检查、检查日期、「关联 Danbooru」，右侧按钮：按相似细分、标为已检查、⋯ 菜单）；其余页用一张「页面名 → [标题, 副标题]」字典；`group` 页另有「整组标为原创角色」，`sgroup` 页另有「判断关系」，资料库角色页另有「N 个自建角色能对上 Danbooru」。

底栏提示在 `grid.js updateCount`（网格页）和各面板页的渲染函数里；空状态文案在 `grid.js reload` 里的一张字典（`unmatched`、`skipped`、`duplicates`、`excluded`、`pending`、`group`、`recent`、`audit`、`library`；角色页单独一句）。

## 3. 浮层

页面上所有"盖在别的东西上面"的层，开、关的先后顺序记在一个栈里，由 `ui/overlay.js`（浮层管理器，#343）统一处理 Esc、点外关闭和焦点归还。各浮层只声明自己是什么类型、怎么关；除管理器之外，前端不再有谁为浮层监听 `document` 的 `keydown` 或 `click`；`tools/check_frontend.py` 的规则 3 只放行 `ui/overlay.js` 这一个文件（用户 2026-11-12 在 #343 批准）。

### 3.1 浮层管理器怎么工作

三种类型（`kind`）：

| 类型 | 是什么 | 点外／点背景 |
|---|---|---|
| `modal` | 模态对话框：`<dialog>` 经 `openModal` 打开。浏览器把它放在顶层，高于所有 `z-index` | 点背景是否关闭由调用点声明（`backdropClose`，默认不关）；它之下的层不响应点外关闭 |
| `popover` | 非模态浮层：菜单、面板、搜索候选 | 点它和它的触发按钮之外的任何地方关闭（点按钮由按钮自己的处理函数开关） |
| `overlay` | 盖满页面的层：导览、大图 | 无 |

规则：

1. **栈按打开的先后排**，后开的在上面。元素被换掉、被藏起来（自己或祖先 `hidden`）、对话框已经关了的层，在下一次 Esc 或点击时自动清出栈，不白占一次按键。
2. **Esc 只关栈顶一个。** 事件在 `document` 捕获阶段处理，处理了就 `preventDefault` 并停止传播，所以同一次按键不会再触发页面别处。对话框由管理器自己 `close()`，返回值与原生取消相同。**栈是空的就放行**，接着走页面自己的 Esc 兜底链（`grid.js`）：输入框失焦 → 详情栏 → 取消选择并退出选择模式。
3. **输入框里按 Esc 只关候选菜单。** 搜索候选菜单（编辑资料、新建作品的 Danbooru 框，资料库"添加关注"）本身是 `popover` 层，叠在所在的对话框或页面上面：它在栈顶，第一下 Esc 只关它，输入框和对话框都留着，第二下才轮到下面一层。
4. **大图让位给输入框。** 大图层声明了 `yieldToInput`：焦点在大图之外的输入框里时，Esc 不关大图，只让输入框失焦（兜底链做）。其余层不让位，例如视图选项打开时，焦点在搜索框里按 Esc 先关视图选项。
5. **点外关闭从栈顶往下数，到第一个 `modal` 为止。** 栈顶的 `popover` 若点在它自己和触发按钮之外就关闭，继续往下看；遇到 `modal` 时只看这次点击是不是它声明了可以关的背景点击，然后停止，所以对话框下面的任务面板不会被对话框里的点击关掉。一次点击可以同时关掉几个它在外面的 `popover`，点中的那个不关。点击本身照常交给被点的元素处理（不吞掉）。
6. **点背景关闭（`openDialog` 的 `backdropClose`，默认 `false`，每个调用点显式写明）：** 只读或确认类（帮助、确认／通知、关系、"按相似细分"、命令面板、只当标签）为 `true`；带输入或选项的表单（编辑资料、新建／编辑作品及关注、关联自建角色、添加新角色、选作品）为 `false`，免得误点丢掉填的东西。
7. **焦点：** 层打开时记下当时的焦点元素。Esc 或选了一项关闭后，焦点还给它（它没了就还给触发按钮），只在焦点仍在层里或在 `body` 上时才还，不从别处抢。点外关闭、页面重画导致的关闭不动焦点。对话框的焦点由浏览器归还。
8. **层级（`z-index`）不由管理器写**，仍是 `app.css` 的 `--z-*` 令牌：非模态浮层 `--z-popover`／`--z-menu`／`--z-overlay`、大图 `--z-overlay`、导览 `--z-guide-tour`；原生 modal 在顶层。栈序决定 Esc 和点外，CSS 决定谁画在上面；两者在正常流程里一致（后开的在上面）。

新增一个浮层：`createLayer({kind, id, el, anchor, onDismiss, …})`（元素会被重画换掉的传函数），打开时 `layer.open()`，用任何途径关掉时 `layer.close(reason)`；`<dialog>` 用 `openModal(dialog, {backdropClose})`，运行时对话框用 `openDialog`（`ui/dialog.js`）。单元测试在 `tests/overlay.test.cjs`。

| 提示条 | `#toast` | 每次操作的结果、撤销 | 3.5 秒（带撤销 6 秒、带按钮 9 秒），鼠标停在上面不消失；无手动关闭 | `--z-toast` | 否 |
| 大图 | `#viewer` | Space、双击、详情里的大图按钮 | Esc、Space、×、点空白（未放大时） | `--z-overlay` | 是（`yieldToInput`） |
| 选择栏 | `#selectionBar` | 选中数 > 0 | × 或 Esc（兜底链） | `--z-bar` | 否 |

详情栏 `#inspector` 是页面内的一列，不是浮层，Esc 由兜底链关；宽度 ≤760px 时改为盖在主区右侧（`--z-page-5`）。三条横幅（错误、损坏、引导提示）是页面内的行，不是浮层。

### 3.3 一次 Esc 的去向

1. 栈里有层：关栈顶那一个，到此为止（大图在焦点位于其外的输入框时除外，见规则 4）。栈里的次序一般就是打开的先后，例如导览 → 任务面板：先关任务面板，再关导览；任务面板 → 它上面开的确认框：先关确认框；对话框 → 它里面的搜索候选：先关候选。
2. 栈空，走 `grid.js` 的兜底链（键盘处理里 `<dialog>` 打开时整个忽略，所以对话框开着时到不了这里）：焦点在输入框 → 只让它失焦；否则详情栏打开 → 关详情栏；否则取消选择并退出选择模式。

## 4. 单张图的三个层次

| 层次 | 元素 | 进入 | 内容 |
|---|---|---|---|
| 详情栏 | `#inspector` | 点卡片（浏览页）、首页点图、↵、选中后方向键之外的 `inspect()` | 上下张、放大、关闭；预览；偶尔一问「是 TA 吗？」；角色卡（名称、收藏曲线、同一角色其他图）；角色（换成、不是、子标签、「也可能是」1–9）；画师；我的标签；重复副本；文件信息和画面标签；底部按钮：更正角色 C／设为角色、跳过 S（仅未识别）、恢复到未识别、排除 X、恢复收录、保留 |
| 大图 | `#viewer` | Space、双击卡片、详情栏放大 | 顶栏：序号、尺寸、‹ ›、×；舞台：滚轮缩放（⌘ 或捏合）、拖动平移、双击切换 1:1；底栏：问题条（深色）和紧凑的角色条 |
| 选择栏 | `#selectionBar` | 选中至少一张 | 见 §4.1 |

### 4.1 选择栏按钮

全局键盘处理有两个入口：浮层管理器（`ui/overlay.js`）在捕获阶段先处理 Esc，栈里有层就关栈顶一个；其余按键和栈空时的 Esc 由 `grid.js wireGrid` 里 `document` 的 `keydown` 处理。表里的「条件」按代码里出现的顺序，前面的条件不满足就不会走到后面。

| 键 | 条件 | 动作 |

| ⌘Z | 不在输入框 | 撤销最近一步（任何页面、任何层次） |
| ⌘A | `#grid` 可见 | 选中全部符合条件的图 |
| Esc | 见 §3.3 | |
| R | 非 `panelPage` | 切换方格／原比例（含大图打开时） |
| H | — | 隐藏／显示 R18（任何页面） |
| / | 页面上有 `#search`（只有图库页） | 聚焦搜索 |

## 6. 状态组合

`core/state.js` 里与「当前是哪张图、选了什么」有关的字段，以及谁写它们：

| 字段 | 含义 | 写入者 |
|---|---|---|
| `selecting` | 选择模式（浏览页点图不再打开详情） | `grid.js`（8 处）、`shell.js applyRoute` |
| `sel` | 选中集：`all` ＋ `ids` ＋ `exclude`；`anchor` 连选起点 | `grid.js` |
| `cursor` | 键盘光标（序号） | `grid.js`、`detail.js`、`shell.js` |
| `focused` | 详情栏里那张图的 uuid（`null` ＝详情栏关） | `detail.js` |
| `detail` | 详情接口的最近一次返回 | `detail.js`（详情栏和大图底栏都写） |
| `viewer` | 大图的序号（`-1` ＝关） | `detail.js` |
| `viewerItem` | 大图里那张图 | `detail.js` |
| `armed` | 等待第二次点击的破坏性按钮名 | `grid.js` |
| `question` | 详情栏或大图里的问题条 | `detail.js` |
| `kept.hold` | 列表变化时保持在视野里的那张图 | `grid.js`、`detail.js` |
| `edits.busy` | 有一项修改在进行 | `grid.js`、`review.js` |

「当前图」有三个来源，优先级 `viewer` ＞ `focused` ＞ `cursor`（`grid.js currentItem`）：快捷键的单图动作作用在它上面。

### 6.1 组合

「可达」指代码允许、且走查里出现过或能手动做出的组合；「不会出现」指代码路径上互相排斥。

| 组合 | 是否出现 | 说明 |
|---|---|---|
| 全无（`selecting=false`、`sel` 空、无详情、无大图） | 默认 | |
| `selecting=true`、`sel` 空 | 可达 | 浏览页点了「选择」，还没选；选择栏不显示，卡片显示圆圈 |
| `selecting=false`、`sel` 非空 | 可达 | 整理页点一张就选中，不经过选择模式；卡片同样显示圆圈 |
| `selecting=true`、`sel` 非空 | 可达 | 浏览页选择模式下 |
| `focused` 有值 ＋ `sel` 非空 | 可达 | 详情栏和选择栏同时在；单图动作和选择动作键位相同，有选中时走选择动作（`n ? runBarAction : singleAction`） |
| `viewer>=0` ＋ `focused` 有值 | 可达 | 从详情栏放大；Esc 先关大图，再关详情栏 |
| `viewer>=0`、`focused` 空 | 可达 | 双击卡片直接开大图 |
| `viewer>=0` ＋ `sel` 非空 | 可达 | 选择栏在大图下方（`z-index` 10 对 40），快捷键仍按选中动作处理，容易误触（见已知问题 7） |
| `armed` 非空 | 只在 `sel` > 500 张时 | 换页、清选择、4 秒后复位 |
| `question` 非空 | 详情栏或大图里有问题条时 | 离开详情栏（无大图时）清空；大图关闭不清，但 Y／N 会核对问题对应的图 |
| `focused` 有值、`detail` 空 | 短暂 | 详情读取中 |
| `detail` 有值、`focused` 空、`viewer<0` | 可达 | 只开过大图（没开详情栏）、关闭大图后：大图底栏读详情会写 `detail`，只有 `closeInspector` 才清它；1–9 要求详情栏或大图在用，所以不会误触 |
| 换页（`applyRoute`） | | 复位 `selecting`、`sel`、`cursor`；详情栏只在换了页面或角色时关；**大图不关**（见已知问题 6） |
| 切换 R18 | | 清选择；不关详情栏、不关大图 |

## 7. 已知问题

只记录，不在 #321 里改。每条标明怎么确认的（读代码／走查）。编号保留原来的：已修的从清单里删去（5、8 在 #343 修了，见 §3），其余编号不动，因为上面的章节按编号引用。

1. **`#/recent` 是孤页。** 侧栏入口 `#navRecent` 在 `index.html` 里带 `hidden`，没有任何代码取消它；全前端也没有指向 `#/recent` 的链接。页面和 `core/route.js`、`grid.js`、`shell.js` 里为它写的分支仍在（2026-10-02 首页接手「新加入」之后遗留）。读代码；走查确认直接输入地址能打开该页，侧栏上该项仍是隐藏的。
2. **`artist-audit` 不在 `panelPage` 里。** 它用 `#groupsPage`，但工具栏走网格页分支，会出现排序、选择、显示方式三个无用控件；按 R、H（R18）、同步到达新图都会调用 `reload()`，后者隐藏 `#groupsPage` 并显示 `#grid`（走查中按 H 之后面板被图库网格替换，计数显示整库 36 张）。读代码并走查确认。
3. **首页上网格快捷键不生效。** 首页隐藏 `#grid`，键盘处理在 `$('grid').hidden` 之后才处理 Space、方向键、↵、C／A／T／S／G／X、⌫、1–9，所以首页点开详情栏后，详情栏按钮旁标的快捷键（C、X…）按了没反应；首页双击开的大图里 ←→、Space 也不生效，只有 Esc 和大图上的按钮。Y／N、⌘Z、H、Esc 在前面处理，照常。读代码并走查确认（首页点图开详情后按 →、Space、C、X、G、1 都没有反应）。
4. **相似组页（`sgroup`）的点击语义夹在两类之间。** `browsing()` 和 `cleanup()` 都为假：点击直接切换选中，却又有「选择」按钮（进入选择模式）；↵ 在无选中时打开详情而不是选中。读代码并走查确认（走查时该页没有真实数据，借用网页内的请求改写把图库前 6 张当作相似组内容）。
6. **换页时大图不关闭。** `applyRoute` 不调用 `closeViewer()`，所以大图打开时（例如在大图上用 ⌘K 跳到角色）页面在大图下面换了，大图继续显示旧图。读代码并走查确认：图库里开着大图（「2 / 36」）改地址到未识别后，大图仍显示原图和旧序号，再按 → 变成「3 / 12」。
7. **选择栏在大图下面仍响应快捷键。** 大图打开时选择栏被盖住，但 C／A／⌫／X／G 仍按选中动作处理。读代码并走查确认（全选后开大图再按 G，弹出的是给全部 36 张加标签的面板）。
9. **底栏默认隐藏。** 每页的 `#hint` 操作提示只在打开「视图选项 › 底部状态栏」后才看得到，默认用户看不到。读代码。
10. **小的死代码。** `updateCount` 的提示字典里有 `character` 键，但页面名永远不是 `character`（角色页走 `route.char` 分支），所以该键不可达；`similar`、`sgroup`、`group`、`recent` 没有提示。读代码。
11. **帮助对话框里的快捷键表是手写的静态文字**，与 §5 不同步的地方：没有 Y／N 的两种用法（抽查、问题条）、⌘K 之外的 ⇧↵ 暂存、T 的限定条件。读代码。
12. **⌘＋／⌘－ 在没有网格的页面上也会改网格缩放。** 它们在「输入框判断」之前处理，不看页面：在设置页按 ⌘＋ 再按 ⌘－，页面上看不出变化，但保存的缩略图大小（`pi.size`）从未设置变成了 166，回到图库后网格列数不同。读代码并走查确认。
13. **整理页里选中后按 ⌫ 没有动作，也不提示。** 键盘处理对「有选中」只在角色页（移出）和浏览页（不是…）有分支，未识别、已跳过、已排除等页没有，按键被吞掉（`runBarAction('')` 什么都不做）。读代码。
