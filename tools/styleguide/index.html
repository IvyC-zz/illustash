关于这页：是什么，怎么用

census.js 过期了。app.css 和统计时不同，令牌表是旧的。重新运行 python3 tools/styleguide/census.py（python3 tools/check_styleguide.py 也会报出这一条）。

给人看：设计是否统一，一眼比较。给代理看：写新界面前先在这里找现成的写法，复用，不要自己造新类名、新数值。找不到合适的，先在 Issue 里问（见 AGENTS.md）。

样式是真的：页面直接引用 web/static/app.css，没有第二套 CSS。结构是抄的：每个样例的 HTML 是对着 web/static/ui/*.js 里的字符串模板手写的。每个条目都写了“生成”：文件和函数名，改模板时回头对一下。等组件收口（#319）后，应改成直接调用生成函数。

有检查兜底：tools/check_styleguide.py（接在 tools/check_all.sh 和 CI 里）要求样例和条目标题用到的每个类都在 app.css 里有样式、census.js 和当前 app.css 一致。改名或删掉一个类、改了 app.css 没重跑统计，都会报出具体的类名、行号和改法。它查不出样例的结构和模板不一致，这一点仍要靠“生成”一栏人工对照。

怎么打开：直接用浏览器打开本文件（file://）；或在仓库根目录运行 python3 -m http.server 8000，再打开 /tools/styleguide/（这样页面自己也会检查令牌统计是否过期）。顶部可切换亮色 / 暗色，和应用里的 html[data-theme] 是同一个机制。

不进发布包：packaging/build.py 只复制 web/static/，本页在 tools/styleguide/，不会被打进去；迁移清点（tools/migration_inventory.py）也把这个目录当开发工具，不算生产代码。

浮层怎么摆在页面里：应用里的 toast、选择栏、任务面板、弹出菜单是 position:fixed/absolute，对话框要 showModal()。这里用 .sg-frozen 把定位和入场动画关掉（styleguide.css 里每条一行），其余样式不动；对话框用 <dialog open>，所以没有遮罩。

数字的口径：令牌表由 census.py 从 app.css 数出来：令牌的“引用”是 var(--名字) 出现的次数；“档位之外”的取值是一处 = 一条规则里的一条声明，取值只做 !important / 0.5→.5 的规范化，不合并相近的取值。。按钮写法的次数是 ui/*.js 与 index.html 里字面的 <button class="…"> 个数（2026-11-12 的 main），动态拼出来的类名不在内。

令牌 · 颜色

颜色变量写在 app.css 开头的 :root 里，按用途分组；暗色在 :root[data-theme=dark] 里成对换值。规则里只引用变量，不写十六进制色，暗色就不用再单独覆盖。新颜色先找现成的一组；确实没有，在两个块里成对加一个变量。

语义色（亮色 / 暗色并排）

--canvas--sheet--ink--tone-*--atag-*…

定义：web/static/app.css 开头的两个主题块，分组标题就是块里的注释；切换：web/static/theme.js 设置 html[data-theme]。色块用各自主题的变量画（两栏各自带一套变量值），后面的数字是 var(--名字) 在 app.css 里被引用的次数。

基础一组的用法：画布 --canvas（页面底）→ 纸面 --sheet（内容区、卡片、浮层）→ --soft（控件底、占位）；文字 --ink / --ink2 / --muted / --faint 由深到浅；--line 实线分隔，--hair 是半透明发丝线（卡片轮廓、阴影的 1px 环）；强调色 --accent（环、勾、进度）、--accent-btn（按钮底，更深）、--accent-soft（选中底）、--accent-ink（强调色文字）；--warn 警示；--r18 / --r18-soft 仅用于 R18 开关。色调 --tone-*-bg / --tone-*-ink 成对用；--ok / --bad / --err 不随主题变。

非颜色的变量

主题块里不是颜色的变量，以及只在局部定义或由 JS 内联写入的自定义属性：--gutter（.content 上，26px；≥1600px 36px；≤1050px 16px；≤760px 12px）、--dup-hue（ui/grid.js 内联）、--p（最近 30 天的圆环，ui/catalog.js 内联）、--depth（作品树缩进，ui/catalog.js 内联）。--panel 在 .aa-card 里被引用（带回退值），但从未定义过。

写死的颜色（没走变量）

存量，不要照抄

这些颜色不会随主题自动换。新代码不要再写；改到附近的规则时顺手换成变量。

令牌 · 字号

正文字号是 --fs-N 一组档位，展示字号（大标题、空状态、启动页等一次性的大字）另有 --fs-display-N，不进正文档位。名字里的数字就是 px 值；新写的值取最近的一档，不要再写档位之外的数。基础字号是 :root 的 var(--fs-13)，用得最多的是 12 和 11。

正文字号

--fs-10…--fs-22

展示字号

--fs-display-17…--fs-display-72

档位之外的写法

口径：font-size 声明与 font 简写里的字号，去掉整条只用令牌的。

令牌 · 圆角

圆角档位

--radius-N--radius-pill--radius-round

小块是 44px 方块上的实际效果。胶囊形（按钮、芯片）用 --radius-pill，圆形（头像、圆点）用 --radius-round。

档位之外的写法

口径：border-radius 与四个单角写法的声明，去掉整条只用令牌（或 0）的。

令牌 · 间距

间距档位

--space-1…--space-24

gap 和 padding 共用一组 --space-N。“样子”画的是两个相邻的块，中间隔开这个宽度。

gap：档位之外的写法

口径：gap / row-gap / column-gap 的声明，去掉整条只用令牌（或 0）的。

padding：常见组合与档位之外的写法

令牌 · 控件高度

控件高度三档

--h-28--h-32--h-36

--h-N 只用于按钮、输入框、下拉等控件的高度；头像、缩略图和图标底板的尺寸不在其内。

其余固定高度

口径：height / min-height 里写 px 的声明（百分比、auto、0 不数）。这里多是图片区、缩略图、进度条和设置行，不是控件；只列出来供对照。

令牌 · 层级

z-index 档位

--z-*

由低到高：页面内局部叠放 --z-page-N < 浮动条 < 浮层 < 抽屉 < 菜单 < 全屏浮层 < 提示条 < 引导 < 启动页。只能新增档位，不要改数值的先后（app.css 里的约定）。

toast（--z-toast）压在查看器（--z-overlay）上，所以看大图时 toast 要移到中下方（body.viewing .toast）。引导的清单、提示条比选择栏高。

组件 · 按钮

按钮收成一组有名字的变体：.primary（强调色主按钮）、.secondary（灰底次要）、.quiet（透明，悬停才有底）、.icon、.link-button；大小 默认 / .small / .large；状态 .on / .armed（#319 合并了原来并行的 .btn / .btn.pri）。另有 .ask-b、.aa-b 等只在局部用的外观和十几种只在一处出现的按钮外观。先看总表，再看每一种的样子。
